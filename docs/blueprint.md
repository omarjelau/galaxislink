# **App Name**: VibeLink

## Core Features:

- User Authentication: Secure user registration and login using Firebase Authentication (email/password, Google login, and anonymous login).
- Link Page Creation: Allow users to create personalized landing pages with a list of links to social media, websites, and shops.
- Digital Business Card: Enable users to create a digital business card with name, job title, company, phone number, email, social media links, and bio.
- QR Code Generation: Automatically generate QR codes for each link page and business card that lead to a public profile page.
- Analytics Dashboard: Track clicks per link (Firestore database) and display statistics (total clicks, origin) in a dashboard.
- Theme Customization: Offer themes, colors, fonts, background images, and animations (like Linktree) to personalize the appearance of link pages and digital business cards.
- AI-Powered Theme Suggestions: Use a tool to provide theme suggestions and design improvements based on the user's content and chosen style to enhance the visual appeal.

## Style Guidelines:

- Primary color: Soft purple (#A084CF), inspired by the blend of professional networking (Vibecard) and social media linking (Linktree), creating a modern, trustworthy feel.
- Background color: Light gray (#F0F0F5), desaturated, for a clean, uncluttered appearance that emphasizes the content.
- Accent color: Blue (#7CB9E8), for call-to-action buttons and highlights, providing a friendly, inviting feel.
- Headline font: 'Space Grotesk', sans-serif, for a modern, tech-forward aesthetic, used for headers and emphasized text.
- Body font: 'Inter', sans-serif, chosen for readability in body text, complementing Space Grotesk while providing a clean, neutral feel.
- Simple, professional icons for links and contact information.
- Clean, intuitive drag-and-drop interface for easy customization.
